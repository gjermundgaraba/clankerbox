# Security policy

Report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/gjermundgaraba/clankerbox/security/advisories/new)
rather than in a public issue. Include the affected component (controller,
host, guest daemon, CLI or release tooling), the version or commit, and a
reproduction.

Only the latest release receives fixes. Each release attaches SHA256 files for
its archives; verify them before extracting.
